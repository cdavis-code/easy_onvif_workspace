# easy_onvif Examples

This directory contains example applications demonstrating how to use the `easy_onvif` package with Dart and Flutter.

## Examples

### Flutter Model (flutter_model/)

A Flutter application that demonstrates:
- ONVIF device discovery on local networks
- Connecting to IP cameras and NVRs
- PTZ (pan-tilt-zoom) controls
- Live video streaming
- Audio streaming
- Event subscription

**Run the example:**
```bash
cd example
flutter run
```

## Getting Started

1. Ensure your ONVIF-compatible device is connected to the same network
2. Update the device credentials in the example code
3. Run the example application

For more detailed examples and CLI usage, see:
- [easy_onvif_cli examples](https://github.com/faithoflifedev/easy_onvif_workspace/tree/main/packages/easy_onvif_cli/example)
- [Full documentation](https://github.com/faithoflifedev/easy_onvif_workspace/tree/main/packages/easy_onvif#readme)
